## About

`ddex-php` is a PHP 7.4+ library for generating and validating compliant XML from [DDEX XSD standards](http://service.ddex.net/xml/).


## Supported Standards

All versioned standards are included. The latest version is shown. See [Implementing each standard](https://kb.ddex.net/implementing-each-standard/) for documentation.

#### ERN: Electronic Release Notification Message Suite ![ERN](https://img.shields.io/badge/ERN-4.3.2-green.svg)

#### MEAD: Media Enrichment and Description ![MEAD](https://img.shields.io/badge/MEAD-1.1-green.svg)

#### PIE: Party Identification and Enrichment ![PIE](https://img.shields.io/badge/PIE-1.1-green.svg)

#### DSR: Digital Sales Reporting Message Suite ![DSR](https://img.shields.io/badge/DSR-4.3D1-green.svg)

#### MWDR: Musical Work Data and Rights communication Standards ![MWN](https://img.shields.io/badge/MWN-10-green.svg)

#### LOD: Letters of Direction Choreography ![LOD](https://img.shields.io/badge/LOD-11-green.svg)

#### RDR: Recording Data and Rights Standards ![RDR](https://img.shields.io/badge/RDR-4.3.1-green.svg)

#### RIN: Recording Information Notification ![RIN](https://img.shields.io/badge/RIN-2.1-green.svg)

#### LRAW: Links between Resources and Musical Work ![LRAW](https://img.shields.io/badge/LRAW-1.1-green.svg)

This includes letters of direction (LoDs).

#### Catalogue Transfers Standard ![CT](https://img.shields.io/badge/CT-1.0-green.svg)



#### AR: Anomaly Reporting ![AR](https://img.shields.io/badge/Unsupported-red.svg)


#### CDM: Claim Detail Message Suite ![CDM](https://img.shields.io/badge/Unsupported-red.svg)


#### Simple Music NFTs ![CDM](https://img.shields.io/badge/Unsupported-red.svg)
